# Susanta Kumar Badatya — Portfolio Website

A cinematic, high-performance personal portfolio website featuring a 3D scroll-driven video sequence animation with smooth LERP physics, responsive design, and modern interactive sections.

## 🚀 Live Demo & Features

- **Smooth Scroll-Based Frame Sequence**: Built with HTML5 Canvas, high-DPI scaling (`devicePixelRatio`), and linear interpolation (LERP) easing.
- **Progressive Buffer & Preloader**: Instant first-frame rendering with background concurrent buffering.
- **Hero Section**: Bold typography, personal branding, role showcase, and live experience statistics.
- **Selected Projects**: Interactive showcase cards with hover-lift micro-interactions.
- **Education & Work Process**: Timeline workflow stages connecting idea to delivery, paired with custom skills matrix.
- **Contact & Attribution**: Quick-connect contact details, custom workstation showcase, and portfolio creator attribution.

## 🛠️ Built With

- **React 19**
- **Vite**
- **HTML5 Canvas (2D Context)**
- **Lucide Icons**
- **Google Fonts** (Bebas Neue, Space Grotesk, Plus Jakarta Sans, Caveat)

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/susanta565/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
